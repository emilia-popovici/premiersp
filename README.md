# PremierAuto

## Pornire

1. Rulează `dotnet restore` și `dotnet build`.
2. Aplică modificarea de bază de date: `dotnet ef database update`.
3. Pornește aplicația cu `dotnet run`.

Migrarea `AddUserNamesAndMechanicDetails` adaugă prenumele/numele conturilor și datele/legătura contului pentru mecanici. Contul de administrator este creat automat cu adresa `admin@premierauto.md`.
